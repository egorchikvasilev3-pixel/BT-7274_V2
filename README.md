# БТ-7274 V2 — локальный голосовой титан

Голосовой агент BT-7274 на Python: HUD-командный центр, прозрачный PySide6-оверлей, F1-рация, faster-whisper, локальная Ollama, управление Windows по командам и голосовой канал с локальным TTS (Piper sidecar) и fallback на Edge TTS.

Репозиторий: [github.com/egorchikvasilev3-pixel/BT-7274_V2](https://github.com/egorchikvasilev3-pixel/BT-7274_V2). Готовые сборки: [Releases](https://github.com/egorchikvasilev3-pixel/BT-7274_V2/releases/latest).

## Что нового в V2.2.0-btvoice

- **Локальный голос БТ**: портативный сайдкар `BT7274_Voice` на Piper/ONNX (`bt7274-ru-medium`, обучен на русских репликах BT). Работает локально, без облачных TTS и без докачек.
- **Быстрее первый звук**: чанковая озвучка с prefetch следующей фразы; полные ответы остаются в субтитрах.
- **Свободная беседа**: память сессии в `OllamaBrain` (последние ходы диалога), обновлённый системный промпт, `think=False` для совместимости с thinking-моделями Ollama.
- **User tools**: пользовательские инструменты из `data/user_tools.json` (безопасные типы действий, подтверждение опасных).
- **Голос**: спокойный размеренный темп, меньше шума и «песка» на согласных, мягкий gate в паузах, нормализация чисел/аббревиатур/сервисов.
- **HUD-эквалайзер**: 13 полос реагируют только на голос БТ (TTS), микрофон на анимацию не влияет.

## Запуск

### Готовый exe

`BT-7274_Command.exe` не требует установленного Python. Запустите exe — откроется командный центр, кнопка «Инициализация нейролинка» поднимет БТ. Агент встроен в тот же exe и запускается внутренним режимом `--agent`.

### Из исходников

```powershell
cd BT-7274_V2
python -m pip install -r requirements.txt
python launcher.py
```

`launcher.py` открывает командный центр. `python main.py` запускает только голосового агента.

### Ollama

Нужен установленный [Ollama](https://ollama.com) и модель по умолчанию:

```powershell
ollama pull llama3.2:3b
```

Модель можно переопределить переменной `BT7274_OLLAMA_MODEL`.

## Управление

- **F1 (удерживать)** — говорить; отпустить — распознать и выполнить.
- **Ctrl+Shift+Q** — аварийный выход.
- **Трей-иконка** — слушать, открыть папку/журнал, выход.
- Повторный запуск второго экземпляра блокируется.

## Установка (для пользователей)

1. Скачайте архив релиза `BT-7274_V2_vX.X.X.zip` со страницы [Releases](https://github.com/egorchikvasilev3-pixel/BT-7274_V2/releases/latest).
2. Распакуйте архив в обычную папку (например `C:\Games\BT-7274` или `Desktop\BT-7274`), **не запускайте изнутри zip**.
3. Убедитесь, что рядом с `BT-7274_Command.exe` лежат файлы из релиза (включая папку/файлы голоса, если они включены в сборку).
4. Установите [Ollama](https://ollama.com) и загрузите модель:

```powershell
ollama pull llama3.2:3b
```

5. Запустите `BT-7274_Command.exe`. Откроется командный центр; нажмите «Инициализация нейролинка».
6. Для голосового ввода держите **F1**, говорите, отпустите F1. Аварийный выход — **Ctrl+Shift+Q**.

Ничего докачивать во время работы не нужно: голосовая модель, eSpeak NG данные и runtime должны поставляться в релизном пакете.

## Голосовой канал

### Локальный голос BT (портативный, по умолчанию)

Основной голос — локальный Piper/ONNX профиль `bt7274-ru-medium` (обучен на репликах BT). Он быстрый, работает локально и не требует облачных TTS.

Что должно быть в комплекте:
- `BT-7274_Command.exe` / клиент BT-7274;
- `voice_server.py` (или упакованный voice sidecar);
- `models/piper/bt7274-ru-medium.onnx` и `models/piper/bt7274-ru-medium.onnx.json`;
- данные `espeak-ng` (для фонемизации Piper);
- Python-окружение sidecar или упакованный sidecar-runtime (в зависимости от сборки).

Переменные окружения:
- `BT7274_TTS_ENGINE` — `piper`/`qwen` (по умолчанию `piper`, если есть `bt7274-ru-medium.onnx`).
- `BT7274_PIPER_MODEL` — путь к `.onnx` модели Piper.
- `BT7274_LOCAL_TTS_URL` — URL sidecar, по умолчанию `http://127.0.0.1:8765`.
- `BT7274_LOCAL_TTS_VARIANT` — `mild`/`raw`/`vanguard`, по умолчанию `mild`.

### Локальный Qwen3-TTS (опционально, тяжёлый)

Для экспериментов можно использовать Qwen3-TTS sidecar (`BT-VoiceLab/voice_server.py`, `BT7274_TTS_ENGINE=qwen`). Это даёт другой тип клонирования, но требует больше места, VRAM и обычно медленнее.

### Fallback Edge TTS

Если локальный sidecar недоступен, используется Edge TTS `ru-RU-DmitryNeural`. Для Edge нужен интернет; в некоторых сетях может потребоваться VPN или `BT7274_TTS_PROXY`. При недоступности Edge ответ остаётся текстом в оверлее.

## Распознавание речи

Whisper пытается запуститься на GPU (`small`, `float16`) при наличии CUDA-библиотек; иначе использует CPU (`small`, `int8`, резерв `base`). В готовом exe CUDA-библиотеки не упакованы — Whisper работает на CPU. GPU-режим доступен при запуске из исходников.

## User tools

Файл: `data/user_tools.json`. Пример шаблона создаётся автоматически/лежит в репозитории.

Поддерживаемые типы `action.type`:
- `open_url` — только `http/https`;
- `open_path` — открыть файл/папку через ОС;
- `open_app` — `.exe/.lnk/.url/.bat/.cmd`;
- `hotkey` — отправить горячие клавиши;
- `insert_text` — скопировать и вставить текст;
- `copy_text` — скопировать текст.

Поля инструмента: `id`, `name`, `enabled`, `triggers`, `match` (`contains`/`exact`/`regex`), `confirm`, `response`, `description`, `action`.

Для `open_path` и `open_app` подтверждение включено по умолчанию. При `confirm: true` БТ попросит сказать «подтверждаю» или «отмена».

## Настройки пилота

В лаунчере: браузер, музыкальный сервис, поисковая система. Настройки сохраняются в `data\settings.json` и применяются сразу.

## Сборка exe

```powershell
python -m pip install -r requirements.txt
python -m PyInstaller --noconfirm --clean --onefile --windowed --icon assets\Icon.ico --collect-data faster_whisper --name BT-7274_Command launcher.py
```

Готовый `BT-7274_Command.exe` кладётся в `dist\` и копируется в корень проекта. Бинарник не хранится в git — публикуется в GitHub Releases с SHA256. См. `RELEASES.md`.

## Важно

- Локальный Qwen3-TTS требует отдельный `BT-VoiceLab` и GPU; в exe не упакован.
- Edge TTS — облачный сервис Microsoft; нужен интернет.
- Whisper в exe работает на CPU; GPU — при запуске из исходников с CUDA-библиотеками.
- Для записи экрана нужен OBS Studio с obs-websocket.
- Очистка корзины необратима — только по явной команде.
- Глобальный F1 в играх/окнах от администратора может требовать запуск от администратора.
- Журнал: `logs\bt7274.log`. Кэш основного клиента (Edge + локальные фразы): `bt_voice_cache`. Кэш сайдкара: `voice_cache` рядом с `BT7274_Voice.exe`.
