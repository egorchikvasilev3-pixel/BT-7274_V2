# БТ-7274 — локальный голосовой титан

Монолитный голосовой ИИ-комплекс на Python: широкий HUD-командный центр 720×480, прозрачный PySide6-оверлей с волновой анимацией карточки BT, F1-рация, faster-whisper на GPU с резервным CPU-режимом, локальная Ollama `llama3.2:3b`, управление Windows по тегам действий и голос Edge TTS с эффектом шлема Vanguard.

Репозиторий и готовые сборки: [github.com/egorchikvasilev3-pixel/BT-7274_V2](https://github.com/egorchikvasilev3-pixel/BT-7274_V2). Скачать exe: [Releases](https://github.com/egorchikvasilev3-pixel/BT-7274_V2/releases/latest).

## Запуск

Готовый `BT-7274_Command.exe` не требует установленного Python: голосовой агент БТ встроен в тот же файл, а лаунчер запускает его внутренним режимом `--agent`. Запустите exe двойным щелчком — откроется командный центр, кнопка «Инициализация нейролинка» поднимет БТ.

Запуск из исходников:

```powershell
cd BT-7274_V2
python -m pip install -r requirements.txt
python launcher.py
```

`launcher.py` открывает командный центр: запуск БТ, журнал, архивы, диагностика и выход. В исходниках агент запускается как `pythonw main.py`; `python main.py` запускает только голосового агента без лаунчера.

При первом запуске из исходников агент сам проверит и при необходимости установит Python-пакеты через `pip`. В собранном exe зависимости уже внутри, установка не требуется. Модель Ollama должна быть установлена заранее:

```powershell
ollama pull llama3.2:3b
```

## Управление

- **F1 (удерживать)** — открыть канал, говорить; отпустить — распознать и выполнить.
- **Ctrl+Shift+Q** — аварийный выход.
- **Иконка в трее** — меню «Слушать», открыть папку/журнал, выход.
- **Выход из лаунчера** — сначала штатно завершает БТ: останавливает запись OBS, выгружает Ollama и закрывает микрофон; принудительная остановка применяется только если БТ не ответил за 5 секунд.
- Повторный запуск второго экземпляра блокируется.

## Командный центр

Окно лаунчера — широкий HUD **720×480**:

- слева — карточка титана BT-7274, класс, пилот, состояние нейролинка и режим F1;
- справа — шесть команд: инициализация нейролинка, журнал синхронизации, архив скриншотов, архив видео, диагностика Ollama и разрыв соединения;
- снизу — живая телеметрия **CPU, RAM, GPU, Ollama и OBS**, а также строка состояния систем.

Телеметрия собирается в фоновом потоке и не подвешивает интерфейс. Загрузка и температура GPU читаются через `nvidia-smi` раз в два цикла; если видеокарта NVIDIA или драйвер недоступны, показывается `N/A`. Кнопка выхода сначала штатно завершает БТ, останавливает запись OBS и выгружает модель, и только потом закрывает лаунчер. Готовый exe собирается из `launcher.py` вместе с агентом `main.py` и не требует установленного Python.

Команды можно формулировать своими словами. Локальный слой подсказок исправляет типичные ошибки маленькой модели: «следующий трек», «тише», «пауза» и подобные срабатывают даже если Ollama перепутала тег.

Явные команды действий и приветствия выполняются **без ожидания Ollama** — сразу запускается действие и берётся заранее подготовленная голосовая фраза. Время, дата, диагностика, буфер обмена, заметки, таймеры, последний клип/скриншот и управление OBS тоже обрабатываются локально. Свободные вопросы по-прежнему идут в локальную модель.

Для скорости частые фразы заранее прогреваются в голосовой кэш, Whisper работает в быстром greedy-режиме, а Ollama при необходимости запускается автоматически. Прогрев Ollama идёт сразу с полным системным промптом и тем же `num_ctx=2048`, поэтому первый ответ после запуска занимает около 0,1–0,2 с, а не 3 с. Модель удерживается в памяти 5 минут; срок можно изменить переменной `BT7274_OLLAMA_KEEP_ALIVE` (например, `2m`, `10m`, `30m`, `1h` или `0` для немедленной выгрузки). При сбое Edge TTS `NoAudioReceived` БТ делает до трёх попыток с паузой 0,4 с; если аудио так и не пришло, ответ остаётся текстом в оверлее. БТ освобождается сразу после ответа, а оверлей с текстом скрывается с задержкой, чтобы успеть прочитать.

## Память

- Ollama держит `llama3.2:3b` в памяти 5 минут после последнего обращения. Это снижает простой ОЗУ и видеопамяти, не замедляя частые команды: при нажатии F1 модель прогревается заранее, пока пилот говорит.
- При нажатии F1 БТ проверяет `/api/ps` и, если модель уже выгружена, прогревает её в фоне параллельно записи речи. Загрузка обычно скрыта под разговором пилота.
- При выходе из БТ и по команде «выгрузи память» модель выгружается сразу через `keep_alive: 0`. Освобождается около 760 МБ ОЗУ и 2,3 ГБ видеопамяти; сам сервер Ollama остаётся в памяти (~50 МБ) и не перезапускается.
- Whisper намеренно не выгружается по простою: CUDA-контекст остаётся занятым, и выгрузка освобождает лишь около 16 МБ. Модель остаётся готовой, чтобы распознавание не теряло скорость.
- Фоновый прогрев идёт с пониженным приоритетом потока, чтобы запуск не подтормаживал систему. На слабом ПК прогрев можно отключить переменной `BT7274_WARMUP=0`: приложение станет легче при старте, но первый ответ и распознавание будут дольше.
- Измеренный рабочий набор: контроллер БТ с GPU-Whisper — около 525 МБ ОЗУ, модель Ollama — около 760 МБ ОЗУ и 2,3 ГБ видеопамяти. После выгрузки Ollama эти 760 МБ возвращаются системе.
- БТ не прописывается в автозагрузку Windows. Если система медленно включается, проверьте сторонние автозапуски (Steam, EA, Discord, Edge, OneDrive): сам БТ стартует только по запуску `main.py` или лаунчера.
- На слабом ПК можно снизить фоновую нагрузку: `set BT7274_WARMUP=0` перед запуском и `set BT7274_OLLAMA_KEEP_ALIVE=2m`. Это ускорит старт и раньше освободит видеопамять, но первые ответы будут чуть медленнее.

## Запись экрана и архив

- Запись идёт через **OBS Studio** по obs-websocket: БТ сам проверяет/выставляет **60 fps**, запускает запись и останавливает её по команде «стоп» или «хватит».
- Если OBS закрыт, БТ попробует найти и запустить `obs64.exe` автоматически.
- Готовые хайлайты сохраняются в `clips\bt_highlight_ГГГГММДД_ЧЧММСС.mp4`.
- Скриншоты сохраняются в `shots\bt_screenshot_ГГГГММДД_ЧЧММСС_мс.png`.
- Лаунчер показывает файлы из `shots\` и `clips\`, а также старые файлы из корня проекта.
- Если в OBS несколько сцен, команда «следующая сцена» переключает их по кругу.
- Заметки хранятся в `data\notes.txt`, журнал — в `logs\bt7274.log`.

## Оверлей и анимация карточки

Оверлей — прозрачное окно **380×370** в правом верхнем углу. Внутри: HUD-карточка BT-7274 **320×180**, планка с именем, классом и состоянием, субтитры и подсказка F1. Окно не перехватывает мышь и не забирает фокус. Пока БТ молчит, оверлей скрыт; карточка появляется по F1 и во время ответа.

Анимация работает с частотой **60 FPS только при активности** и останавливается в простое, поэтому не нагружает систему постоянно:

- при ответе БТ по карточке идут волны, как в HUD Titanfall 2: горизонтальные полосы со сдвигом, синусоидальные голографические линии, пульсирующее кольцо и проходящая полоса сканирования;
- при слушании и ответе — мерцание прозрачности, редкие горизонтальные срезы, шумовые вставки и скобки захвата;
- статичные сканлайны и шумовые тайлы кэшируются, анимация привязана ко времени, а не к количеству кадров; используется `PreciseTimer`, поэтому скорость не зависит от загрузки CPU.

Цвет карточки — только синий BT: акцент `#00e8ff`, без красных и посторонних оттенков. Частоту можно ограничить переменной `BT7274_OVERLAY_FPS` (допустимо 30–60, по умолчанию 60):

```powershell
set BT7274_OVERLAY_FPS=30
```

## Голос

Основной голос — `ru-RU-DmitryNeural`, замедленный до `-6%`, с понижением тона `-12Hz`, полосовым фильтром 100–7400 Гц, подъёмом низа/презенса, коротким эхом, лёгким фленджером и мягкой сатурацией. Металлические эффекты ослаблены, чтобы речь оставалась разборчивой. Это не клон реального актёра: голос Радика Мухаметзянова не используется и не клонируется. Подача и тембр приближены к «военному» русскому дубляжу.

Если Edge TTS не отдаёт аудио, БТ повторяет запрос до трёх раз и **не подменяет голос** другим: после исчерпания попыток ответ остаётся текстом в оверлее. Русские голоса Edge могут быть недоступны в отдельных сетях — помогает VPN или прокси, заданный в переменной `BT7274_TTS_PROXY`. Уже синтезированные фразы берутся из кэша и звучат мгновенно.

## Распознавание речи

Whisper сначала пытается запуститься на GPU: модель `small`, `float16`. Для этого нужны `nvidia-cublas-cu12` и `nvidia-cudnn-cu12` (DLL подхватываются автоматически):

```powershell
python -m pip install nvidia-cublas-cu12 nvidia-cudnn-cu12
```

Если CUDA-библиотек нет или GPU-инициализация сорвалась, БТ без падения переходит на CPU: модель `base`, `int8`, 4 потока. При первом GPU-запуске модель `small` скачивается в локальный кэш faster-whisper. На RTX 5060 после прогрева фраза длиной около 6 секунд распознаётся примерно за 0,2 с; холодная загрузка модели занимает около 5 с и идёт в фоне при старте.

В готовом exe CUDA-библиотеки не упакованы из-за размера: Whisper автоматически работает на CPU. GPU-режим доступен при запуске из исходников после установки пакетов NVIDIA.

## Сборка exe

```powershell
python -m pip install -r requirements.txt
python -m PyInstaller --noconfirm --clean --onefile --windowed --icon assets\Icon.ico --collect-data faster_whisper --name BT-7274_Command launcher.py
```

В сборку попадают и лаунчер, и голосовой агент: при `--agent` exe запускает встроенный `main.main()` без внешнего Python и `main.py`. Готовый `BT-7274_Command.exe` кладётся в корень проекта.

Сам бинарник в репозиторий не входит (см. `.gitignore`) — для GitHub его публикуют в разделе **Releases** вместе с SHA256:

```powershell
Get-FileHash BT-7274_Command.exe -Algorithm SHA256
```

Пошаговая инструкция публикации — в `RELEASES.md`.

## Важно

- Edge TTS — облачный сервис Microsoft. Для него нужен интернет; всё остальное (Whisper, Ollama, фильтр, действия) работает локально.
- Для записи экрана нужен установленный OBS Studio с включённым obs-websocket (порт 4455). БТ читает порт и пароль из конфига OBS.
- `[EMPTY_TRASH]` необратим. Команда выполняется только при явной формулировке про корзину.
- Для игр/окон, запущенных от администратора, глобальный F1 может потребовать запуск exe или `main.py` от администратора.
- `helmet.webp` — HUD-карточка идентификации титана BT-7274; используется в лаунчере и оверлее. Для замены сохраните пропорции 16:9 и прозрачный фон. В release-архиве файл лежит рядом с exe; без него включается резервный векторный шлем.
- Журнал: `logs\bt7274.log`. Кэш голоса: `bt_voice_cache`. Старые версии: `_legacy`.
